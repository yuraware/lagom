### Added
- `install.sh` now does the whole setup: on macOS with Homebrew it installs or upgrades `yuraware/tap/lagom` (falling back to the verified archive if that fails), adds an `lgm` alias unless another `lgm` exists, and runs `lagom install --yes` to add the hooks to every agent found. A second run upgrades or says lagom is already up to date. New options: `--no-agents` and `--no-brew` (or `LAGOM_NO_AGENTS=1`, `LAGOM_NO_BREW=1`).
