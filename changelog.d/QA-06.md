### Fixed
- Four or more `npm ERR!` lines that differ only in a number are no longer folded into `… [N similar lines]`: every line the error rule protects now counts as important everywhere output is cut.
- Compressed output is never longer than the input: a repeat count, a similar-lines note or a `…[+N chars]` cut is used only when it is shorter than what it replaces.
- Compression is about 10% faster: error lines are found with one lowercase copy of each line and a fast substring search.
